## AvansKeuzeKompas Front-End

## instalatie

Clone de repository en installeer alle benodigde dependencies:

```sh
npm install
```

Start een development server:

```sh
npm run dev

# of start de server en open de app in een nieuwe browser tab
npm run dev -- --open
```

## Als je aanpassingen wil maken aan de 'scss' file, dan wil je deze command runnen:

```sh
# Deze command kijkt naar de .scss file en compiled het live naar .css als je aanpassingen hebt gedaan
# Buiten dat werkt het hetzelfde als de npm run dev command

npm run start:dev
```

## Builden

Om een productie versie van de app te maken:

```sh
npm run build
```

De command waarmee de app online runt:
```sh
npm run start
```
